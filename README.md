# Password Generator

A simple web application that generates two random secure passwords. Each password contains a mix of uppercase letters, lowercase letters, numbers, and special characters.

## Features

- Generates two random passwords simultaneously
- Each password is 15 characters long
- Includes a variety of characters for maximum security:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (~`!@#$%^&*()_-+={}[]|:;<>.?/)

## Usage

1. Open the application in your web browser
2. Click the generate button to create two new random passwords
3. The passwords will be displayed on the screen
4. Generate as many passwords as needed

## Technical Details

Built using:
- HTML
- CSS
- JavaScript

The generator uses JavaScript's Math.random() function to select random characters from a predefined character set.
